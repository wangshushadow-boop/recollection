2026-11-26。游戏提交 `bdd47cc`，开发基线 `9c5d7f1`。从[普通入口](../../../../../启动游戏.cmd)或[C++ 常驻试玩入口](../field-resident/试玩常驻版野战.cmd)选择河原野战。两版现有镜头和快捷键见[操控表](../field-controls/README.md)。

## 战场界面

顶部显示双方在场人数及比例，右下角显示本人生命条、生命值、当前武器和弹药。按数字选兵后，编队卡显示已确认的友方兵种、人数和阵型；命令卡显示可用快捷键。按住 Tab 显示分阵营战况。按 Esc 或切走窗口后，中央菜单提供返回战场、设置、部队指挥、撤退。打开菜单时，单机河原继续模拟。部署时只显示一个「开始野战」入口。没有标记预设阵形时直接按默认方案开战，已标记阵形时先提交部署。截图中的 `field.deployment` 可由旧面板提交空部署草案触发，旧回执还会留到开战后。

界面采用项目原创 Godot 控件；参考的是《骑马与砍杀 II：霸主》的兵力条、个人状态和编队卡的信息安排。没有投影的数值不补造。[TaleWorlds 开发更新 #10](https://www.taleworlds.com/en/News/495) · [新版战斗画面](battle.png) · [编队指挥](orders.png) · [Esc 菜单](menu.png)

## 为什么敌兵不打玩家

河原以 60 Hz 模拟。战术层通常每秒决定一次全队目标，编队层每秒约三次把目标转成守阵、推进、冲锋、撤退或重整等约束。个体层通常每秒五次分批处理士兵，紧急反应可提前调度。每名士兵从自己的可见敌人中选择可达的目标，考虑距离、阵位、附近友兵及当前锁定目标。近战起招、蓄力、挥击和命中由战斗模块依次裁定，角色是玩家也可成为敌人的目标。

旧版实测中，第 3 号蓝方步兵已经看见并选中了玩家。其编队正在重整，当时实际执行的是原地坚守。允许主动接敌的标志是 false，原有判断把原地近战一并挡住。修复后，原地坚守及执行坚守令的重整部队可对 1.45 米内的可见、可达敌人原地起招。站在攻击范围内的敌人优先于远处目标。守兵不会因此追人，敌人退开后，蓄好的近战动作可以挥空并恢复。行军、正在移动的重整、撤退及溃逃仍走原有决策。近战距离、攻击频率和碰撞伤害使用既有规则。

普通无头对照使用种子 241124，500 兵、100 马，玩家不发令，沿相同侧翼路线走向蓝军并停下。第 1796 步进入 1.45 米；旧版在范围内观察 181 步，对方一直处于 Ready，玩家 100 HP。修复后，第 1812 步同一名敌兵近战命中 14 点，玩家 86 HP。伤害取自实际攻击者和目标的战斗记录。
