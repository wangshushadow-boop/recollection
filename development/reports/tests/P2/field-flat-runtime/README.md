## 代码和性能归因

注入的基础设施适配器在当前任务的独立物理世界里检查相关静态碰撞体及其真实形状、世界变换。只有能确定唯一相关碰撞体为未旋转的静态盒体，且整段球扫的最低点高于盒顶并留足接触余量，才跳过该步的精查。地面和墙共用碰撞体、动态门、新形状、未知场景均可回到原查询。起跳和落地继续使用原检测。每次重读场景也包含在上述计时中。此优化面向由当前适配器管理的场景，直接往其独立物理空间插入无节点 RID 的第三方扩展未验证。

较晚在引擎内部跳过实际查询的隔离方案仍需逐兵构造和检验请求，一轮平均 11.90 FPS。选择在移动侧尽早跳过请求。这个隔离轮与改名前的试验均单独归档。正式基线和最终版的碰撞行为及帧率分别复测。

优化后最大战斗子阶段为 AI，每步平均 11.54 ms，完整移动为 10.84 ms。轻量轮中，每显示帧的非 field_step 墙钟时间平均 19.04 ms。细采样中，present_frame 平均 9.89 ms，其中取得可视快照 6.22 ms，应用快照 2.54 ms。客户端输入及步后处理共 4.56 ms/帧，插值显示回调 2.00 ms/帧。根视口 GPU 计时平均 5.60 ms，与 CPU 时间可重叠。30 FPS 目标及现实每秒 60 步均未达到。
