# 河原野战双将、枪盾与短弓

## 操作

从主菜单进入河原野战，点「开始野战」。红方由玩家直接控制，蓝方由 AI 控制。两军各从自己的首批名册中出一位步战将军。将军站在阵列前方中央，使用阵营披风、铠甲、铜色肩甲和带盔缨的头盔。

| 操作 | 战场反馈 |
|---|---|
| 移动鼠标选择方向，按住左键，再松开 | 长枪分别使出左挥、右挥、上劈或刺击。起手方向锁定，准星显示对应方向。 |
| 右键防御 | 举盾护住选定方向。起手与蓄势中可变招举盾，出手和收势用现有权威动作窗判断。举盾时按左键可转入反击。 |
| 滚轮向上 | 在长枪圆盾和短弓间轮换。HUD 显示实际在手的兵器和下一个切换目标。默认小键盘 1、2 也可直接选近战、远程。 |
| 持弓按住左键、松开 | 左手持弓，右手将箭拉至脸侧，松开发一箭。准星随拉弦收紧，箭从角色的位置按实际俯仰飞行，命中由战斗物理判定。 |
| 拉弓时按右键 | 放下弓，不发箭、不扣弹药。换回近战仍可使用原有枪盾。 |

## 实现与判定

主将行装由内容包定义。COM 按 60 Hz 维护准备、保持、有效、恢复与盾耐久。主将近战的准备、有效、恢复分别为 9、4、9 步，短弓分别为 18、3、9 步。弓准星参考箭起点向前 20 米的位置，远近落点仍受实际发射点、重力和遮挡影响。盾防沿用护盾覆盖体和方向判定。手上模型、箭弦和骨骼从已提交的阶段与武器类型取样。[战斗设计](../../../../../docs/systems/game/mission/combat/README.md)

将军外形和战斗兵种分开选择。将军与普通骑兵沿用同一套已授权的 General 美术源文件，步战首领有自己的枪盾挂点、肩甲和阵营披风。原步态会同时大幅压弯两节胸椎，再由头颈反向补偿。新步态缩小上身倾斜幅度，保留骨盆位移与迈步；动作结束后从步态重新采样，再叠加下一次上身动作。将军的枪盾使用真实武器网格和源模型的手掌握点。[视觉设计](../../../../../docs/systems/game/presentation/visuals/README.md) · [资产署名](../../../../../game/content/base/field/CREDITS.md)

开场阵位由实际名册、阵营和部署区分配，将军占用独立前排位置。按阵型手动先布置弓兵时也要留出该位置。战斗开始后，玩家可以离开前排，敌方将军可以跟随其 AI 寻敌。部队阵列不能把直接控制的玩家拉回士兵队列。

## 无头验证

游戏版本 `6cc04e6`。Godot 4.7.2 Standard，河原 500 名士兵、100 匹马。两位将军各占本方的一个现役名额。

| 场景 | 实际结果 |
|---|---|
| 默认开战、玩家不输入 | 第 1 步，红蓝将军在中线两侧相向而立，各领先本方最近的前排士兵 2.90 米。第 181 步红将仍在原地，蓝将已自主寻敌，两人分别领先 1.43、3.75 米。 |
| 先手动部署弓手，再持续提交零移动输入 | 两将仍在正中领先 2.90 米开战；第 181 步分别领先 1.25、3.04 米。500 个兵员出生点互异。 |
| 将军战损与增援 | 504/504。敌将倒下后记录在原名册中；普通增援复用实体索引时，不会继承首领身份。 |
| 持弓奔跑 | 90 帧内上胸最大侧倾由 52.57° 降至 16.99°。头胸最大夹角 8.03°，横向偏移最多 2.4 厘米；腿部相对原步态的最大角误差 0.04°。 |
| 枪盾与骑乘 | 长枪和圆盾最近的网格表面分别距右、左腕 7.9 和 5.3 厘米；举盾后仍与双手相随。骑乘视觉 102/102。 |
| 战斗、输入与界面 | 真实 AI 接战管线普通和常驻版各 273/273；INPUT 1020/1020，重试 49/49，HUD 203/203；主将与四类普通兵的装备定义校验通过。 |

在较早候选中，玩家静止时曾被编队拉回，另有枪盾偏离手掌。最终版已分别用持续零位移输入、实际武器网格与实机近景复验。初次测试也曾错误要求进入战斗后的 AI 将军持续站在中轴，最终用例检查开场居中和实际领先距离，允许接敌时侧移。

## 桌面实测

Windows、RTX 3090、Forward+、960×600。在独立的用户配置目录中，从主菜单进入河原并点击「开始野战」。两组脚本分别操作真实的玩家输入、读取战场结算，以及采集渲染后的画面与模型姿态。桌面证据包含脚本参数、源文件摘要、各项断言与运行日志。[证据包](evidence.zip)

| 用例 | 普通版 | 常驻版 |
|---|---:|---:|
| 四向攻防、切换武器、拉弦和收弓、俯仰与实际命中 | 80/80 | 81/81 |
| 将军开场站位、双方远近模型、双手握持、迎面持弓跑及收弦后再跑 | 35/35 | 36/36 |
| 实射敌将 | 19.73 米，躯干扣 20 生命 | 19.73 米，躯干扣 20 生命 |

常驻版两次均核实运行中实际调用 C++ 移动内核。两版命中各消耗一支箭，右键收弓没有消耗。旧基线的桌面攻防测试执行了 55 项，其中 7 项失败，四向格挡的姿势区分和滚轮切弓均未达到判据。此次测试关注功能与动作，没有采集整场帧率。
