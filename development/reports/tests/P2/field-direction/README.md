# 河原野战角色、镜头与骑乘操控验收

2026-11-26。游戏提交 `0da6355`。此批验收单机战场玩家操控，由 INPUT、MOV、MIS-RT、VIS 联合实现，任务为 P2-INPUT-004、P2-FIELD-INTEGRATION-047/048/049 和 P2-VIS-BATTLE-007。普通启动脚本加载工作区，常驻启动脚本从该提交导出游戏，叠加已同步的移动及运行时脚本。两份脚本的摘要已核对，C++ 内核 DLL 与上一试玩版本相同。

## 玩家操作

| 场合 | 操作反馈 |
|---|---|
| 第三人称自由步战 | 鼠标环视。WASD 和斜向组合决定行进方向，身体逐步转向行进方向。固定镜头按 A、D 显示左右侧面，按 S 朝镜头跑，松键保留朝向。 |
| 攻击、格挡或第一人称 | 身体随瞄准方位，仍可横移和倒退。R 切换第一、第三人称。按住自由观察键可转动观察视角。 |
| 骑乘 | W 提速，S 降档至停，松开保持当前档位。A/D 转马，可一边转马一边环视或瞄准。马身按实际朝向绘制，近景骑手可独立转动上身。 |

原先移动位移已按镜头水平轴计算，身体却把镜头朝向当作全部移动方向的目标。之前只查位移和格挡，漏掉了自由移动中的模型正面。现在在输入层分别求取移动、观察、身体及瞄准方向，战斗步提交后由视觉层绘制。骑乘另修正了移动层将连续小转向判断为必须先刹停的条件，急转仍会制动并重新校验导航路段。[完整状态表、设计依据与原作资料](../../../../../docs/systems/game/presentation/input/README.md)

## 桌面实测

Windows、Godot 4.7.2、RTX 3090、Forward+、960×600。步战从主菜单进入普通的河原野战，500 兵、100 马，经过部署按钮，在离开拥挤的起始阵列后输入八方向。读取实际可见模型的正面轴、世界位移、战斗朝向及镜头轴，另保存渲染截图。骑乘另用相同河原和战斗控制器的两人配马场景，确保验到真正骑马的主角。

| 桌面用例 | 旧常驻版 `6733b06` | 新普通版 | 新常驻版 |
|---|---:|---:|---:|
| 步战方向及战场进出 | 49/59 | 58/58 | 59/59 |
| 骑乘环视、行进、转弯与制动 | 13/20 | 20/20 | 20/20 |
| 固定镜头自由向后走时，模型正面与镜头前方夹角 | 0° | 180° | 180° |
| 右转 65 步的行程（骑乘） | 见下方分步对照 | 9.75 米 | 9.74 米 |

旧版七个非 W 方向都仍与镜头同向。新版八向的模型正面均与位移同向。双入口均观察到转身中间姿态、按键释放后保留朝向、格挡横移和第一人称后退时保持瞄准。常驻版第 59 条检查确认默认战场有实际原生内核调用，两人配马用例未达到原生合批门槛。[左移截图](left.png) · [向镜头跑截图](back.png) · [右移截图](right.png)

骑乘单独对照了接通马匹操舵后、修复导航制动前的中间版本。持续 D 的 65 个战斗步累计只走 0.036 米，全部低于 0.2 米/秒；最终普通版同样输入右转 61.69°、走 9.75 米，常驻版右转 60.82°、走 9.74 米，两者均无停滞步。普通版松 W 后 48 步仍走 4.27 米，按 S 降档后最终停止。

## 无头回归与复现

Godot 4.7.2 的 INPUT 930/930，输入重试 49/49，骑乘显示 95/95，带实际 AI 的骑乘战斗流水线 157/157。MOV 小角度转弯、急转、障碍、导航预算及回滚回归，普通版及常驻版分别 4761/4761。使用旧 MOV 运行新回归有两条持续转弯断言失败。独立代码审查通过。

在仓库根目录将 [桌面探针、日志和量测数据](evidence.zip) 解包到一个可写目录，以本机 Python 运行该目录的 `run.py game normal` 或 `run.py game mount-normal`。先运行常驻版启动脚本的 `--check-only`，再把项目参数换为 `out/resident/play-0da6355/game` 并加入 `--native`。骑乘组的结果名以前缀 `mount` 选择探针。无头移动回归命令为 `Godot_v4.7.2-stable_win64_console.exe --headless --path game --script res://tests/p2/move_intents/run.gd`。

此次依据原作公开接口与项目试玩要求制定操控规则。转身速率和三档前进步速是本项目的调校值。未做商业原版逐帧动画对照、实体手柄或新一轮帧率采样。远景简化骑手与马共享全身朝向，仅近景模型分离上身与鞍座。
