## 实现和行为验证

- field_pipeline.gd 复用稳定成员映射和槽位目标，AI 接收 MOV 的位置和朝向列。阵型槽位投影改变地形反馈或当前命令时，AI 读取 FORM 当步的最新状态。
- field_brains.gd 仅在名册或相关版本变化时重新校验全量输入。每步更新全军感知位置，按调度组装个体输入、计算阵型中心和最大槽位误差。
- field_combat.gd 在战斗权威域记录生命、弹药、士气变化，并维护骑乘和持盾的只读索引。输入随事务分支提交或丢弃。
- 行为回放采用相同五条命令。逐步比较实际可见角色、投射物和战斗事件摘要，并在第 986 步注入失败，检查上一步的可见状态和成功重试。

独立无头验收使用 500 名士兵、100 匹马。第 1–1260 步的摘要 1260/1260 一致，汇总 SHA-256 为 `8f52df5f89f6d652ff9beaa6cdc7ee0132c90bf2056f3de366747d6c1b8405a8`。全程发射 88 次，有效命中 61 次，造成 2112 点伤害。第 986 步注入错误后时钟仍为 985、已发布的画面未变，重试结果与参考相同。
