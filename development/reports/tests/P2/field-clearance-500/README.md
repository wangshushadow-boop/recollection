# 河原野战 · 稳定开战性能与平地筛选实验

基线为 `codex/p2-field-frame-preview` 的 `0e7fef8`。正式候选 B 的 `game/infrastructure/engine/queries.gd` SHA-256 为 `a05e79b963d5bc296844f80b80feec28b40db770bec9eacc9e18eb679d2e315f`。保留的是批内复用排除表和命中表、仅多个命中时排序，以及复用首段起点变换。权限、AI 调度、移动网格、物理频率和物理追赶上限沿用基线。整场性能仍低于 P2 门槛。

## 桌面实测

Windows，Intel Core Ultra 9 285K、RTX 3090、Godot 4.7.2 Standard，960×600 默认画质，种子 241124。脚本打开主菜单，进入河原野战，在布阵界面等待 45 个显示帧，点击「开始野战」后不动、不发令。每轮实际记录 500 名士兵、100 匹马。每次在独立进程运行，图形轮之间顺序执行。稳定步为 121–440。进场资源初始化和部署阶段保留在原始记录，不纳入稳定段或本次修改。

## 移动、AI 与地面筛选

两版各有一轮在同一场战斗同时拆解移动与 AI 的细采样。数据按步在内存累积，退出时一次写盘。每步平均值如下，父子时间有重叠。完整明细包含每阶段均值/P50/P95、对象定义与数量、实际工作量定义与数值。获得、切换或丢失目标等纯计数指标的耗时列留空。[子阶段全表](stages.csv)

**平坦地面确实干扰水平粗筛。** 河原地面是一块顶面 y=0 的盒体。基线中粗扫返回的命中行全部带 ground 标记。过半格子被标记为占用后，现有逻辑回退到连续 30 个步号范围内的精确检查。基线和正式候选均保留这种行为。

为评估这个建议，另在隔离副本中仅针对这张无额外墙体的平地忽略粗筛的 ground 命中。地图、种子、人数、输入、精细计时和画质一致。在一轮带探针的候选 B → 平地实验中，精扫从 475.26 次/步降至 0，粗扫从 1.13 增至 33.04 次/步。净空耗时 4.29→0.96 ms，`_walk` P50/P95 为 13.42/15.43→10.35/11.68 ms，`field_step` P50/P95 为 33.44/37.91→30.70/34.45 ms；帧 P50/P95 为 301.49/336.12→280.92/305.12 ms，平均 3.28→3.53 FPS，现实步速 26.24→28.27。实验后 `_think` 平均 11.72 ms，高于 `_walk` 的 10.52 ms。单轮结果用来选择下一步，未当作交付帧率。

直接忽略 ground 标签会把同一地形碰撞体的边缘或侧壁一起忽略。本次评估只在隔离副本采用它。正式实现应能证明水平扫掠与可通行的平坦表面分离，保留同格其他墙、门、坡沿、单面薄面和未分类形状的精查，单独回归起跳与落地。下一轮如处理 AI，仅去掉只读修订/权限查询的成员复制；0.41 ms 是本窗口全部这类复制的实测总量。按名册版本做更广复用仍须独立对照，特别是同一步撤权、死亡补员和失败回滚。

## 迭代、失败和行为验收

- 第一试验只在有命中时创建临时状态，单组 FPS 3.198→3.271。B 改成批内复用；首批三个 A/B 后追加三轮反向顺序对照，采用上面的六轮结果。
- 另一候选 C 尝试在起点 `intersect_shape` 为空时省略 `get_rest_info`。在平坦站立与常规接战中未显出差异，但真实薄板反例推翻了等价性假设。厚度 20 mm 的板顶 y=10 mm，半径 280 mm 的球从 [0,290,0] 至 [8,292,1]，基线报告起点命中，C 漏报。720 次边缘查询中 C 有 154 行不同，涵盖 15 个不同的整毫米输入。C 已撤回，正式 B 与基线 720/720 完全一致。新增固定回归在 A/C/B 上分别为 37/37、36/37、37/37。
- **无头行为对照。** 在单独的有指令河原场中，500 人＋100 马，前后 1,260/1,260 个逐步状态摘要相同。第 986 步首次敌对正伤害，88 次发射、61 次正伤害、共 2,112 点。步兵、弓手、骑兵和骑射最大移动分别为 70.15、67.37、78.74、88.21 米。另有 40 人＋8 马 2,100/2,100 步相同，自然胜利和俘获 594/594，物理代理及运动回滚等专项通过。[独立 QA](qa-report.md) · [含原始失败的行为证据](qa-evidence.zip)
- 两版另外各通过 6,403 项平地、骑乘、实墙、跳跃和落地检查。正面遇墙均停在 x=−0.504494 m，平地起跳顶点 0.961805 m，低顶顶点 0.540309 m，台阶落点 y=0.45 m，河原边界落点 z=89.99945 m。[逐项输出和复跑程序](locomotion-evidence.zip)
- 本轮正式代码只涉及 `game/infrastructure/engine/queries.gd` 和 `game/tests/p2/field_sweep_batch/run.gd`。未测 1000 人、完整 P2 阶段、其他硬件或不同后端；已锁定引擎的运行配置返回 DEFAULT。
