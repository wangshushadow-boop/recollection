# 河原野战镜头与键鼠

2026-11-26。分支 `codex/p2-field-frame-preview`，基线 `a6a2555`，游戏代码 `5df3b64`。从[普通版](../../../../../启动游戏.cmd)或[C++ 移动常驻版](../field-resident/试玩常驻版野战.cmd)进入「河原野战」，点击「开始野战」。两版使用同一套镜头、操控和 HUD。主菜单、部署、战果使用可见光标。

## 操作

| 操作 | 默认 PC 键鼠 |
|---|---|
| 转身、前后左右移动 | 鼠标、WASD。Caps Lock 切换步行和跑步 |
| 第一／第三人称 | R。小键盘 + 拉近、− 拉远跟随镜头 |
| 放大观察 | 按住 Shift，松开回到原视野 |
| 回头观察 | 按住数字 1 左边的反引号键并移动鼠标，松开回到原瞄准方向 |
| 攻击、格挡 | 左键按下蓄力、松开挥击；右键格挡或取消尚可取消的攻击。鼠标移动选择方向 |
| 互动与骑乘 | F 互动／上下马，Z 蹲伏／骑乘时请求下马，空格跳跃，滚轮向上切换可用武器 |
| 选兵 | 主键盘 1–9 按编号选队，0 全选，Shift 加编号增减选择 |
| 移动与冲锋 | F1 再按 F1 到准星指向的地面，F1 再按 F3 普通冲锋，F1 再按 F2 跟随指挥官所在编队 |
| 阵型与战术 | F2 阵型，F3 战术，F4 射击开关，F5 上下马，F6 委派，F7 朝向，F8 盾墙，F9 横列 |
| 战况与菜单 | 按住 Tab 看双方兵力，Esc 或右键关闭已打开的快捷命令。Esc 可打开操作面板，Esc 或「返回战场控制」恢复。B 为项目兼容的独立指挥模式 |

第三人称的默认后距为步行 2.65 米、骑乘 3.40 米。镜头在人物右肩后，靠墙时收短，离开后平滑伸出。自由观察只旋转镜头。第一人称下隐藏本人遮挡镜头的模型部件，保留装备、坐骑和其他角色；当前人物使用合并蒙皮，尚无独立的第一人称裸手模型。

参考《骑马与砍杀 II：霸主》的 PC 版指挥分组与快捷令。距离、偏移和镜头跟随速度按本项目角色尺寸实调。针对某一敌阵的冲锋可在面板选择可见敌阵；当前快捷冲锋是普通冲锋。「跟随」使用既有的编队跟随命令。踢击、盾击、丢弃武器、切换武器模式、滚轮向下切盾，以及完整原作兵令均未复现。[官方指挥菜单](https://www.taleworlds.com/en/News/413) · [F4–F9 按键](https://www.taleworlds.com/en/News/427) · [官方定向冲锋说明](https://www.taleworlds.com/en/News/547)

## 独立验收

Windows、Godot 4.7.2 Standard、RTX 3090、Vulkan Forward+、960×600、河原 500 兵和 100 马。独立 QA 通过实际渲染的窗口派发鼠标和键盘事件，真实点击主菜单、部署、开战和撤退按钮。切至独立系统窗口验证失焦。主 Agent 检查日志、断言和截图。此批未测试物理手柄、与原作并排的主观手感或帧率变化。

| 运行 | 结果 |
|---|---|
| 普通客户端 | 49/49，退出码 0 |
| C++ 常驻试玩客户端 | 50/50，退出码 0。额外验证移动内核实际调用 331 次 |
| 无头镜头，镜头重入，跨进程设置 | 109、167、19 项通过 |
| 无头输入，重试，输入控制权交接 | 395、49、32 项通过 |
| 无头 HUD，骑乘视觉 | 163、91 项通过 |

两版均验证同一已提交战斗步内转动镜头、沿相机朝向前进、自由观察与攻击方向隔离、缩放与距离恢复、第一人称近景遮挡、方向攻防、战况、准星移动令、普通冲锋、窗口失焦与显式恢复、撤退返回主菜单。独立审查复核了取点、指挥模式、上下马及镜头权限恢复。首次测试的 12 步位移窗口内尚未取得路线；诊断跟踪显示输入已经送达，普通版在第 32 步获得路径，第 40 步已沿预期方向移动约 0.51 米。另一次桌面回归发现确认撤退可能遇到画面和模拟的版本差。修正后两版均可完成撤退。带目标的命令仍使用原有权限和版本校验。

## 复现

将证据包解压到仓库的 `out/field-controls-qa/`。在仓库根目录执行以下命令。桌面驱动为每轮建立独立用户目录，不会覆盖玩家存档。无头测试示例使用同一 Godot 控制台程序运行 `--headless --path game --script res://tests/p2/input/run.gd`。

```powershell
python out/field-controls-qa/run.py game normal-rerun
& './development/reports/tests/P2/field-resident/试玩常驻版野战.cmd' --check-only
python out/field-controls-qa/run.py out/resident/play-5df3b64/game native-rerun --native
```
