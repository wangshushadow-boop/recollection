# 河原野战移动第二版

代码 `7313995`，同轮基线 `d073df6`（第一版）。任务 P2-FIELD-INTEGRATION-030、031、032。项目负责人选择行为等价的移动优化，保留原有接战和让行顺序。

## 桌面实测

## 改动与取舍

- MOV 复用已确认的近邻接触。直接移动的起点、实际候选终点、阻挡位置及半径和均相同时，沿用让行结果；一旦变化就按原顺序检查。普通编队侧移礼让始终保留原有裁决。当前场景地形最高点和已认证路径的高度范围证明整批扫掠有净空时，省去逐人准备水平查询。墙、门、斜坡、高海拔和跳跃仍经过相应检测。
- 编队布局重建时，按阵型与步骑通行类型各设置一次共享走廊，每名士兵仍单独入路和分配槽位。12 人夹具中，12 次走廊设置降低到 4 次，两个版本均分配 12 个槽位。
- 兵马顺序稳定时复用上步物理和战斗位姿，按实际变化更新物理槽位。号码与世代、骑乘关系、盾牌和编队变化都有相应检查。物理引擎在整批校验成功后应用更新，失败按原事务恢复。

## 无头行为验收

- 500 人、100 匹马的有指令接战，1260/1260 个可见状态、投射物与战斗事件摘要一致。共 88 发、61 次有效命中、2112 点伤害。第 986 步故障注入后仍发布第 985 步状态；重试后首伤、命令、移动距离及最终摘要一致。
- 密集近战另用真实 AI、MOV、COM 和 Jolt。双方各 16 名纯步兵，180 步内平均每步 67.43 对敌兵相距不超过 2 米。两版均在第 20 步首次近战命中，8 名攻击者造成 23 次有效命中、322 点伤害，投射物为 0。逐步摘要一致。该小场用于确认近战手感相关的可观察行为；其无头耗时不计入桌面 FPS。
- QA 的碰撞代理 106 项、移动与障碍 410 项、上下马与跳跃 75 项通过。新增 MOV 等价性定点回归 28 项通过，含门廊横移、动态墙、短路径、坡道、半径、邻居同格移动、世代复用和 48 人检查上限。独立审查发现初稿保存了门廊修正前的目标点，交付版保存实际参与碰撞测试的落点。首次外置移动测试脚本因父夹具加载失败未执行，修正测试入口后通过。

本轮每种桌面场景仅一组对照。未运行千人性能、长时多人压测或人工手感盲测。P2 整体门禁仍待验收。
